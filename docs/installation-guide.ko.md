# Hermes Easy Setup 설치 설명서

연구실 구성원을 위한 Windows 설치 안내

작성 기준: 2026년 9월 14일 · 마법사 0.3.0 · 코드 67c6e86

이 문서는 공개용 설치 안내입니다. 실제 서버 주소와 내 PC의 NetBird 주소는 관리자에게 확인하세요. `<...>`로 표시한 값은 입력 형식 설명이므로 그대로 붙여 넣지 않습니다.

이 설명서는 내 Windows PC에 Hermes 에이전트를 설치하고 연구실 Mattermost에서 대화할 수 있도록 연결하는 방법을 안내합니다. 명령어를 직접 입력하지 않고 마법사 화면을 따라 진행합니다.

**대상은 Windows 10 또는 11의 x64 PC입니다.** WSL, Linux 서버, GB10, macOS 설치 절차는 포함하지 않습니다. 다른 PC에서 전체 설치와 연결이 성공하는지는 마지막 대화 테스트까지 확인해야 합니다.

## 시작 전에 준비하기

- **Git for Windows**를 설치합니다. [공식 다운로드 페이지](https://gitforwindows.org/)에서 받고 설치 위치는 기본값인 Program Files 아래를 사용합니다. 이미 설치되어 있다면 다시 설치할 필요 없이 마법사의 PC 확인부터 진행합니다.
- **NetBird를 연구실 네트워크에 연결**합니다. 설치만 끝내지 말고 로그인과 연결까지 완료합니다. 신규 구성원은 관리자에게 연구실 접속 안내를 받습니다. [NetBird Windows 설치 안내](https://docs.netbird.io/get-started/install/windows)
- 브라우저에서 **관리자가 안내한 연구실 Mattermost 서버 주소**를 열어 접속되는지 확인합니다. 사람 계정으로 로그인하고 사용할 팀과 채널에 들어갈 수 있어야 합니다. Mattermost 데스크톱 앱은 필수가 아닙니다.
- 사용할 **ChatGPT 또는 Codex 계정**을 준비합니다. 해당 계정에서 Codex를 사용할 수 있어야 합니다. 이 마법사에는 별도의 OpenAI API 키를 입력하지 않습니다.
- 관리자에게 **나에게 배정된 봇의 사용자 이름, 봇 토큰, Home channel ID**를 받습니다. 이미 다른 PC에서 사용 중인 봇 토큰을 그대로 쓰지 않습니다.
- Dashboard에 사용할 사용자 이름과 **새 비밀번호**를 정해 둡니다. Windows, Mattermost, OpenAI 비밀번호와 구분합니다.
- 설치 후반에 Windows 관리자 승인 창이 나타납니다. 승인할 수 없는 PC라면 관리자와 먼저 일정을 잡습니다.

관리자 준비 항목은 문서 마지막의 **관리자 확인 사항**을 참고합니다. 이 마법사가 Mattermost 서버 설치나 봇 계정 생성을 대신하지는 않습니다.

## 전체 순서

파일 다운로드 → 1단계 PC 확인 → 2단계 설치 동의 → 3단계 자동 설치 → 4단계 Codex 인증과 모델 선택 → 5단계 연구실 연결 → Mattermost 대화 테스트

현재 배포물은 연구실용 커뮤니티 마법사이며 Nous Research의 공식 제품은 아닙니다. 다운로드와 설치 시간은 PC와 네트워크 상태에 따라 달라집니다.

## 1 설치 파일 다운로드와 실행

1. [Hermes Easy Setup GitHub 저장소](https://github.com/harrypotter8473/hermes-easy-setup)를 엽니다.
2. 초록색 **Code → Download ZIP**을 누릅니다. 또는 [최신 main ZIP 다운로드](https://github.com/harrypotter8473/hermes-easy-setup/archive/refs/heads/main.zip)를 사용합니다. 예전에 받아 둔 ZIP이나 오래된 Release는 사용하지 않습니다.
3. 다운로드한 ZIP을 우클릭하고 **압축 풀기 또는 모두 추출**을 선택합니다. 압축 파일 내부에서 바로 실행하지 않습니다.
4. 압축을 푼 폴더 안의 **Start-HermesEasySetup.cmd**를 더블클릭합니다. 일반 실행으로 시작하면 됩니다.
5. **Hermes Easy Setup** 창이 열리면 아래 순서로 진행합니다.

Windows가 실행을 차단하면 다운로드 출처와 경고 내용을 관리자에게 확인받습니다. 백신이나 보안 정책을 통째로 끄지 않습니다.

## 2 마법사 1단계에서 3단계까지

### 1단계 PC 확인

1. **PC 확인 시작**을 누릅니다.
2. 점검 결과에서 필수 항목이 통과했는지 확인합니다.
3. **설치 계획 보기**를 누릅니다. Git 등 필수 항목에 문제가 나오면 먼저 해당 항목을 해결하고 PC 확인을 다시 실행합니다.

**기존 설치 설정 계속**이 나타나면 마법사가 기존 설치를 확인한 상태입니다. 이 버튼으로 설정을 이어갈 수 있습니다. 아무 Hermes 설치나 자동으로 이어 쓸 수 있다는 뜻은 아닙니다.

### 2단계 설치 계획 검토

1. 설치 위치와 변경 내용을 읽습니다. Provider는 **OpenAI Codex로 고정**되어 있습니다.
2. 설치 계획에 동의하는 체크박스를 직접 선택합니다.
3. **설치 시작**을 누릅니다.

Hermes Desktop 자동 빌드나 Computer Use 등 회색 옵션은 선택하지 않는 항목입니다. 비활성화 상태가 정상입니다.

### 3단계 설치와 검증

로그와 진행률을 보며 자동 설치와 검증이 끝날 때까지 기다립니다. 설치 중에는 창을 닫거나 두 번째 마법사를 실행하지 않습니다.

정상 완료되면 **4 / 5 Codex 인증과 모델** 화면으로 이동합니다. 실패하면 오류 문구를 남기고 **진단 ZIP 만들기**가 표시되는 경우 이를 이용합니다. 처음부터 폴더를 삭제하거나 다른 설치 명령을 섞어 실행하지 않습니다.

## 3 마법사 4단계 Codex 인증과 모델 선택

### 처음 로그인하는 경우

1. **Codex OAuth 로그인**을 누릅니다.
2. 브라우저가 열리지 않으면 **인증 페이지 열기**를 누릅니다.
3. 주소가 **https://auth.openai.com/codex/device**인지 확인합니다.
4. 사용할 ChatGPT 또는 Codex 계정으로 로그인합니다. 브라우저가 코드를 요청하면 마법사의 **일회용 인증 코드**를 입력하고 승인을 마칩니다.
5. 마법사로 돌아와 인증 상태가 바뀔 때까지 기다립니다. 인증 작업 중 일부 버튼이 회색으로 보이는 것은 정상입니다.
6. 인증이 확인되면 **기본 Codex 모델**을 선택합니다. 기본 선택이 gpt-5.6-terra로 표시된다면 그대로 시작할 수 있습니다. 목록은 설치 버전이나 계정에 따라 달라질 수 있습니다.
7. **다음: 에이전트 설정**을 누릅니다.

이미 유효한 인증이 있으면 브라우저를 새로 열지 않고 진행할 수 있습니다. 다른 계정으로 바꿔야 한다면 기존 인증을 무심코 사용하지 말고 관리자에게 계정 전환을 요청합니다.

브라우저에서 승인이 끝났는데 다음 버튼이 켜지지 않으면 잠시 기다립니다. **상태 새로고침**이 활성화되어 있으면 한 번 눌러 확인합니다. 계속 대기하면 오류 해결 항목을 확인합니다. 인증 코드나 인증 화면 전체를 단체 채팅에 올리지 않습니다.

## 4 마법사 5단계 에이전트 프로필 입력

프로필은 이 PC에서 에이전트의 이름, 역할, 메모리와 대화를 구분하는 공간입니다. 아래 예시는 입력 방법을 보여 주기 위한 것으로 이름과 역할은 본인 용도에 맞게 바꿉니다.

| 화면 항목 | 입력 예시 | 뜻과 주의할 점 |
| --- | --- | --- |
| Profile name | lab-agent | PC 안에서 쓰는 프로필 이름. 영문 소문자로 시작하고 소문자·숫자·밑줄·하이픈으로 2~32자. default는 사용하지 않습니다. |
| Full name | 리서치 도우미 | 에이전트가 사용할 이름. 한글도 가능합니다. Mattermost의 @호출용 사용자 이름과는 구분합니다. |
| Role / responsibilities | 논문 검색과 핵심 요약을 담당합니다. 답변에 출처를 함께 제시합니다. | 에이전트에게 맡길 역할을 적습니다. 나중에 변경할 수 있습니다. |

**같은 이름의 기존 프로필이 있으면 이어서 설정**은 이전 시도에서 만들어진 동일 프로필을 재설정할 때만 선택합니다. 기존 프로필의 이름·역할·연결 설정이 변경되므로 다른 용도로 쓰는 프로필을 선택하지 않습니다. 처음 설치라면 체크하지 않고 진행합니다.

## 5 Mattermost와 Dashboard 연결값 입력

5단계 화면을 아래로 스크롤하며 **Mattermost 연결**, **Hermes Dashboard와 자동 시작**을 차례로 채웁니다. Dashboard는 연구실 Bot Control이 내 PC의 Hermes 설정을 관리하기 위해 연결하는 관리 화면입니다.

| 화면 항목 | 무엇을 입력하나요 | 주의할 점 |
| --- | --- | --- |
| Server URL | 관리자가 안내한 실제 서버 주소 | 입력 형식은 `http://<Mattermost-서버주소>:8065`입니다. 관리자 안내가 HTTPS나 다른 포트라면 그대로 따릅니다. 뒤에 `/팀/channels/채널` 같은 경로를 붙이지 않습니다. 마법사에 주소가 미리 입력되어 있어도 실제 서버와 일치하는지 확인합니다. |
| Bot token | 관리자가 전달한 해당 봇의 토큰 | 사람의 로그인 비밀번호나 Token ID가 아닙니다. 이 문서나 단체 채팅에 적지 말고 입력칸에만 붙여 넣습니다. |
| Home channel ID | 관리자가 전달한 홈 채널 ID | 채널 이름 agent 또는 채널 URL과 다릅니다. 모르면 임의의 값을 넣지 말고 확인합니다. 기본 알림 등을 보낼 채널입니다. |
| NetBird IPv4 | 감지 버튼으로 찾은 내 PC 주소 | 설치 중인 PC의 NetBird 주소입니다. Mattermost 서버 주소나 다른 사람의 PC 주소를 입력하는 것이 아닙니다. 자동 감지가 안 되면 관리자에게 내 PC의 주소를 확인받습니다. |
| Port | 9119 | Dashboard가 사용할 포트입니다. 특별한 안내가 없다면 기본값을 유지합니다. |
| Username | admin | Dashboard 로그인용 사용자 이름입니다. 특별한 안내가 없다면 기본값을 유지합니다. |
| Password | Dashboard용으로 정한 새 비밀번호 | OpenAI 또는 Mattermost 로그인 비밀번호를 넣는 칸이 아닙니다. 이후 관리에 필요하므로 안전한 곳에 보관합니다. |

### 주소 두 개를 구분하세요

**Server URL은 연구실 서버 주소**, **NetBird IPv4는 설치 중인 내 PC 주소**입니다. Dashboard 주소는 `http://<내-PC의-NetBird-IPv4>:9119` 형태로 만들어집니다. 실제 주소는 **감지** 버튼이나 관리자 안내로 확인하며, 다른 사람의 주소를 복사하지 않습니다.

127.0.0.1은 자기 컴퓨터만 가리키므로 다른 서버가 내 Dashboard로 연결할 주소로 쓰지 않습니다. 0.0.0.0도 이 입력칸에 쓰는 접속 주소가 아닙니다.

**연결 시 전달되는 정보:** 봇 토큰으로 Mattermost에 인증하며, Dashboard 주소·사용자 이름·비밀번호와 프로필 정보 등을 Bot Control에 전달합니다. 올바른 연구실 서버 주소인지 확인하고, 다른 서비스에서 쓰는 비밀번호를 재사용하지 않습니다.

## 6 연결을 시작하고 완료 확인하기

1. 입력을 마쳤으면 **연구실 연결 시작**을 누릅니다.
2. 프로필 준비 후 자동 시작 작업을 등록한다는 안내를 확인합니다.
3. 이번 설치가 연 Windows 관리자 승인 창에서 **예**를 누릅니다. 승인이 어려우면 관리자에게 요청합니다.
4. Dashboard 준비에는 **최대 4분**이 걸릴 수 있습니다. 전체 설치 시간이 아니라 이 단계의 대기 시간입니다.
5. **연구실 연결이 완료되었습니다**와 함께 프로필, Dashboard 주소, **Bot Control 등록: True**, **Gateway 실행: True**가 표시되는지 확인합니다.

완료 화면에서 프로필 이름과 Dashboard URL을 기록해 둡니다. 비밀번호나 토큰은 완료 보고 메시지에 함께 적지 않습니다. 오류가 나면 이미 생성된 프로필이 있을 수 있으므로 [오류 해결 항목](#9-진행이-멈추거나-오류가-날-때)의 재시도 방법을 사용합니다.

## 7 Mattermost에서 직접 테스트하기

연구실 Mattermost의 사용할 채널로 들어갑니다. @를 입력한 뒤 목록에서 **내 봇 계정**을 선택해 아래 네 가지를 확인합니다. Full name을 일반 글자로 쓰는 것과 실제 @멘션은 다릅니다.

| 테스트 | 보내는 방법 | 정상적으로 기대하는 결과 |
| --- | --- | --- |
| 채널에서 호출 | 봇을 @멘션하고 “안녕. 네 이름과 역할을 한 문장으로 알려줘.” | 같은 채널의 일반 대화로 답합니다. |
| 호출하지 않음 | 새 일반 메시지로 “오늘 회의는 세 시입니다.” | 봇이 답하지 않습니다. |
| 기존 스레드에서 호출 | 기존 메시지의 답글을 열고 봇을 @멘션해 질문합니다. | 해당 스레드 안에 답합니다. |
| 봇과 직접 대화 | 봇의 DM을 열고 인사합니다. | DM에서는 @멘션 없이 답합니다. |

관리자에게 Bot Control 목록에도 내 봇이 등록되었는지 확인받습니다. 등록과 실제 대화까지 확인해야 설치를 마친 것으로 봅니다.

## 8 설치 후 사용하는 방법

마법사는 닫아도 됩니다. Gateway는 메시지를 주고받는 연결 프로그램이며 Dashboard와 함께 **Windows 부팅 시 숨김 작업으로 시작**하도록 등록됩니다. 별도로 터미널을 계속 열어 두지 않아도 됩니다.

PC가 꺼져 있거나 절전 상태이거나 NetBird 연결이 끊기면 응답할 수 없습니다. 자동 업데이트는 **PC 현지 시간 기준 매주 일요일 04시**에 예약됩니다. 전원이 꺼져 있으면 그 시각에 실행되지 않으며 다시 실행 가능한 시점에 처리될 수 있습니다. 이후 PC를 재부팅했을 때도 대화가 되는지 한 번 확인합니다.

사용자 ID별 제한 없이 봇이 접근할 수 있는 대화의 사용자를 허용합니다. Hermes의 도구는 내 PC의 사용자 권한으로 동작하므로 연구실 구성원과 관리자에게 맡길 작업 범위를 공유해 둡니다.

## 9 진행이 멈추거나 오류가 날 때

### 창이 안 열리거나 실행하자마자 닫힘

ZIP을 완전히 압축 해제했는지, Start-HermesEasySetup.cmd를 실행했는지 확인합니다. 예전 폴더와 새 폴더를 섞어 쓰지 않습니다. 경고나 오류 화면을 관리자에게 전달합니다.

### Python 설치 또는 설치 검증 단계에서 실패

GitHub main에서 최신 ZIP을 받았는지 확인합니다. **PC 확인**을 다시 수행하고, **기존 설치 설정 계속**이 나타나면 이를 사용합니다. Python·저장소·무결성 관련 오류가 반복되면 진단 정보를 전달합니다. Hermes 폴더를 임의로 삭제하거나 검증을 끄지 않습니다.

### 브라우저 인증은 끝났는데 다음 버튼이 비활성화됨

마법사에서 이번에 표시한 코드로 승인했는지 확인합니다. 예전에 열어 둔 인증 창과 혼동하지 않습니다. 마법사 상태 갱신을 기다린 뒤 **상태 새로고침**이 가능할 때 확인합니다. 계속 멈추면 관리자에게 4단계 상태 문구만 전달하고 인증 코드나 토큰은 가립니다.

### 관리자 승인이 취소되어 종료 코드 70이 표시됨

프로필이 이미 저장되었을 수 있습니다. 같은 창에서 **기존 프로필로 다시 시도**를 눌러 이어가고, 자동 시작 등록 안내와 Windows 승인 창을 확인합니다. 마법사를 다시 열었다면 동일 프로필 이름과 **같은 이름의 기존 프로필이 있으면 이어서 설정**을 사용합니다.

### Dashboard가 제한 시간 안에 준비되지 않음

NetBird가 연결되어 있는지, NetBird IPv4에 서버 주소가 아니라 **내 PC 주소**가 들어갔는지 확인합니다. 9119 포트를 다른 프로그램이 사용 중일 수도 있습니다. 관리자에게 이 PC의 Dashboard 실행 상태와 Windows 방화벽을 확인받습니다. 주소를 127.0.0.1로 바꾸거나 방화벽 전체를 끄지 않습니다.

### Bot Control 등록 실패 또는 서버에서 접근 불가

관리자가 Bot Control 0.6.0 이상이 활성화되어 있는지, 봇 토큰이 유효한지, **Mattermost 서버에서 내 PC의 Dashboard 포트로 연결할 수 있는지** 확인해야 합니다. 내 브라우저에서 Dashboard가 열리는 것만으로 서버의 접근까지 확인된 것은 아닙니다. 이미 Gateway가 켜져 있을 수 있으므로 새 설치를 여러 개 시작하지 않습니다.

### 설치는 끝났지만 봇이 답하지 않거나 두 번 답함

실제 봇 사용자 이름을 @멘션했는지, 봇이 팀과 채널의 멤버인지 확인합니다. 두 번 답하면 같은 토큰으로 Windows·WSL·다른 PC에서 Gateway가 동시에 실행 중인지 관리자에게 확인받습니다. 같은 봇을 새로 연결할 때는 기존 실행을 정리해야 합니다.

### 관리자에게 보내면 도움이 되는 정보

어느 단계인지, 오류 문구, Windows 버전, 마법사를 받은 날짜, 프로필 이름을 알려 주세요. **진단 ZIP 만들기**가 보이면 파일을 생성하되 공유 전에 내용을 확인하고 관리자에게 비공개로 전달합니다. 봇 토큰, Dashboard 비밀번호, OAuth 인증 코드는 보내지 않습니다.

## 10 관리자 확인 사항

설치자가 첫 페이지부터 따라 할 수 있도록 관리자가 다음 항목을 먼저 준비합니다.

1. 설치할 PC가 연구실 NetBird 네트워크에 참가하도록 안내하고 필요한 승인을 마칩니다. 신규 사용자가 별도의 개인 네트워크를 만드는 것과 구분합니다.
2. 설치자에게 연구실 Mattermost 사람 계정을 안내하고 사용할 팀과 채널에 초대합니다. 다른 Mattermost 서버에서 만든 계정이 자동으로 공유되지는 않습니다.
3. 설치자에게 배정할 **별도 봇 계정**을 만들고 팀과 채널에 추가합니다. 봇 사용자 이름과 실제 봇 토큰을 안전한 방법으로 전달합니다. Bot token과 Token ID는 다릅니다. [Mattermost 봇 계정 공식 안내](https://developers.mattermost.com/integrate/reference/bot-accounts/)
4. 실제 Mattermost 서버 주소와 Home channel ID를 설치자에게 비공개로 전달합니다. 채널 ID는 채널 이름이나 URL 대신 실제 값을 전달합니다.
5. Mattermost 서버에서 **INFONET Bot Control 0.6.0 이상** 플러그인이 정상적으로 시작되어 있는지 확인합니다.
6. NetBird 정책과 방화벽에서 **설치 PC → Mattermost 서버 8065**, **Mattermost 서버 → 설치 PC Dashboard 9119** 연결을 확인합니다. 사용자 지정 포트라면 실제 포트를 사용합니다.
7. 설치 후 Bot Control 등록, Dashboard 인증, 채널·스레드·DM 동작을 확인합니다. PC 재부팅 후 자동 시작도 별도로 확인합니다.

## 11 저장 위치와 관리할 때의 주의점

Windows 파일 탐색기 주소창에 아래 경로를 붙여 넣으면 폴더를 열 수 있습니다. %LOCALAPPDATA%는 현재 사용자의 AppData\\Local 폴더를 뜻합니다.

| 저장 내용 | 기본 위치 |
| --- | --- |
| Hermes 설치와 설정 | %LOCALAPPDATA%\\hermes |
| Hermes 소스 코드 | %LOCALAPPDATA%\\hermes\\hermes-agent |
| 에이전트 프로필 | %LOCALAPPDATA%\\hermes\\profiles\\lab-agent |
| 마법사 실행 기록과 진단 자료 | %LOCALAPPDATA%\\HermesEasySetup |

프로필 예시 lab-agent는 본인이 정한 이름으로 바꿉니다. 프로필에는 연결 설정과 기억이 들어가므로 오류 해결을 위해 무작정 삭제하지 않습니다. 이 마법사는 제거·초기화 기능을 제공하지 않습니다.

Windows **작업 스케줄러**에는 **Hermes Easy Setup Gateway - 프로필명**, **Hermes Easy Setup Dashboard - 프로필명**, **Hermes Easy Setup Weekly Update - 프로필명** 형태의 작업이 등록됩니다. 관리자 점검 시 이 작업을 확인합니다. 다른 자동 시작 방법을 추가하면 중복 실행될 수 있습니다.

같은 PC에서 Dashboard 인증값은 여러 프로필에 영향을 줄 수 있습니다. 추가 프로필이나 여러 Dashboard를 운영할 때는 포트와 인증 설정을 관리자와 조정합니다.
