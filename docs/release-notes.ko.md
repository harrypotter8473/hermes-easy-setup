자동 분업 연구팀과 Word 보고서 기본 출력을 포함한 Windows 설치 마법사입니다.

- Research: 개인 연구실용 4역할 설치 마법사. 총괄 계획 → 조사 → 중간 감사 → 분석 → 중간 감사 → 총괄 종합 → 중간·최종 감사 → Word 첨부를 프로그램이 진행합니다.
- 여러 줄 과제의 모델 응답 규격 오류를 수정했습니다. 일시적 모델 오류와 복구 가능한 형식 오류는 2·5·10초 간격으로 최대 3회 재시도합니다.
- 보고서는 기본적으로 .docx 파일로 같은 Mattermost 스레드에 첨부됩니다. 실제 다운로드 해시 검증까지 설치 테스트에 포함합니다.
- 봇 간 응답은 멘션이 있을 때만 이루어지고, 관리 에이전트만 다른 봇의 답변을 자동 관찰합니다.
- User ZIP은 연구원 PC용, Admin ZIP은 별도 서버 관리자용입니다. 개인 연구실은 Research ZIP을 압축 해제한 뒤 Start-HermesResearchSetup.cmd를 실행하세요.

미서명 Windows x64 빌드입니다. 각 ZIP의 FILES.sha256과 전체 ZIP의 SHA256SUMS.txt를 제공합니다. 검색 서비스의 차단·장애, 인증 오류, 사용 한도 초과는 보류될 수 있습니다. 감사 통과는 사실의 절대적 보증이나 사용자의 공식 최종 승인을 뜻하지 않습니다.

학술 자료는 검색어에 site:arxiv.org 를 포함하면 공식 arXiv API로 검색합니다. 반환된 초록 메타데이터는 원문 열람으로 세지 않으며 read_web을 별도로 실행해야 합니다. 일반 웹 검색의 장애·차단이 해소되었다는 뜻은 아닙니다. API 안내: https://info.arxiv.org/help/api/user-manual.html
